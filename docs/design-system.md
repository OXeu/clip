# Clip · Fluent 2 界面规范

使用微软 .NET 自带的 `PresentationFramework.Fluent` 和浅色主题。应用操作图标使用 [Remix Icon](https://remixicon.com/)，直接以原始 SVG 路径转成 WPF Geometry，无网页容器或图标字体依赖。原生控件的弹出层、焦点、禁用态和滚动条保留微软 Fluent 模板。

所有应用窗口移除左上角品牌图标和 Clip 品牌标题；主界面页头仅显示当前剪辑摘要，与下方内容保持 24 DIP 左对齐，不保留原品牌区的占位和分隔线。系统标题栏保留功能名称及原生窗口控制，不显示应用图标；按钮和素材的功能图标不受影响。

## 四原则

| 原则 | 实现 |
| --- | --- |
| 对比 | 中性浅色工作区衬托画面；主操作和选中片段为品牌蓝；整轨选择使用整行浅蓝和左侧色条，状态栏另有选中轨道的文字提示；标题、正文和辅助信息分级 |
| 对齐 | 页面统一 24 DIP 外边距，普通面板 20 DIP、紧凑属性栏 16 DIP 内边距；标签、输入和解释左对齐；播放控制居中，时间读数两端对齐 |
| 重复 | 所有面板、按钮、文字和时间轴共用语义令牌；按钮高度 36 DIP，圆角 4 / 8 DIP，应用图标为 20 DIP Remix 矢量 |
| 亲和性 | 片段名称、速度、时长放在时间轴片段上；编辑操作集中在右键菜单；轨道导出选择位于导出按钮内部右侧；导出参数与其解释放在同一组 |

## 渐进式披露

| 状态 / 操作 | 显示内容 |
| --- | --- |
| 未导入 | 单一主入口“导入视频”及拖放提示，隐藏素材栏、播放控制、导出和时间轴 |
| 已导入 | 每个素材进入独立候选轨，有任意非空轨道即可导出；预览占满内容行，片段属性面板及其占位完全移除 |
| 选中片段 | 预览跟随片段，启用右键删除、复制和命名；不会隐式指定导出轨道 |
| 选中轨道 | 点击轨道空白处，整行高亮；点击导出直接打开该轨道的导出设置 |
| 导出 | 默认显示质量和尺寸，编码器收在“高级设置”；移除硬件解码开关及说明，使用软件解码 |
| 自定义尺寸 | 仅选择自定义后显示宽高输入；验证失败在字段下方显示错误 |
| 设置 | 日常入口保持一个按钮；FFmpeg 目录及 NVIDIA 诊断放在高级子菜单 |

分割、删除、复制、命名、撤销、重做通过时间轴右键菜单操作，保留原有分割、删除及历史快捷键。时间轴和预览面板均移除整个 header 及其高度，内容从面板顶部开始；时间轴保留标尺和底部摘要，预览保留底部播放控制。移除缩放滑块和“适应”按钮，缩放保留 Shift / Ctrl + 滚轮。右键片段先选中并定位，右键标尺、空轨及面板底部可打开同一菜单而不改变当前选择；不可用操作禁用，忙碌期间所有菜单操作禁用。

复制时，时间轴时长 < 10 秒的副本插入原片段之后，≥ 10 秒的副本进入原轨道正下方的新候选轨道。命名使用独立的小窗口，空名称内联提示，保存后名称出现在时间轴上；不修改源文件，复制和命名均可撤销。

导出按钮在两条以上轨道有内容时显示内部右侧箭头，展开列表仅包含非空轨道，按画布顺序列出轨道名、片段数和时长。未选整轨时，单条非空轨道可直接导出，多条则展开列表；点击列表项直接打开对应导出设置。导出高级设置展开时自动滚动到新出现的控件。

多轨共用一把冻结标尺，左侧仅保留 16 DIP 内边距，不显示轨道名称和说明，也不保留冻结名称列。片段显示自定义名称（未命名时为文件名）、速度和时间轴时长，拖拽时用插入线明确落点。播放头只突出当前预览轨道，主轨始终位于最上方，所有非空轨道都可导出。纵向浏览使用滚动条或 Alt + 滚轮。

## 令牌与代码

- `Design/FluentTokens.xaml`：中性、品牌、错误及预览语义色，字体、字号、4 DIP 间距刻度和圆角。
- `Design/FluentStyles.xaml`：继承原生 Fluent 按钮模板的主、次、轻量操作，以及统一面板和文案样式。
- `Design/RemixGeometry.xaml`、`RemixIcon.cs`：图标几何与原生矢量渲染；颜色继承按钮状态。
- `TimelineControl.cs`：画布也消费相同语义色和字体，避免出现独立的一套样式。

主要颜色：背景 #F5F5F5 / #FFFFFF，正文 #242424，辅助文案 #616161，品牌 #0F6CBD，品牌浅底 #EBF3FC，错误 #B10E1C。正文 14、辅助文案 12、区域标题 16、页面标题 24–28 DIP。普通文本组合满足至少 4.5:1 的对比度；选中状态另有文字提示，非仅靠颜色。

## 验证

Windows UI 验证流程用两个不同方向、帧率和音轨配置的真实视频，检查多素材导入、原生鼠标跨轨拖拽和轨内排序、分割、复制、命名、撤销、整轨选择与导出菜单、候选轨连续播放及跨素材播放，并保存空态、导入后、多轨、命名、菜单、最小窗口及导出设置截图。Linux 本地只执行编译、核心和 FFmpeg 测试，不声称执行了 Windows UI 验证。

设计依据：[Fluent 2 布局](https://fluent2.microsoft.design/layout)、[字体](https://fluent2.microsoft.design/typography)、[颜色](https://fluent2.microsoft.design/color)、[按需展开](https://fluent2.microsoft.design/components/web/react/core/accordion/usage)、[WPF Fluent 主题](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/whats-new/net90)。
