# 使用 Clip

## 整理片段

每个导入的视频都会生成一条视频轨，并在其下方固定附带一条伴生音频槽；即使素材无声，槽位也会保留。音频槽使用源音频的真实波形显示音量高低，分割视频或伴生音频时会同步分割另一条轨。拖动左侧把手可以调整轨道组顺序，视频轨与它的伴生音频槽会始终一起移动。点击片段预览，右键打开编辑菜单；片段可在同类型轨道之间拖动，同轨片段自动紧接排列。预览默认完整适应可用区域；在预览画面上滚动鼠标滚轮可缩放，双击恢复适应。

时间轴工具栏提供分割、删除、撤销和重做。右侧的“− / 适应 / +”调整缩放；“适应”显示完整时间轴。界面跟随 Windows 的浅色、深色或高对比度设置。

点击片段只选中片段；点击轨道空白处才会选中整轨。多条轨道有内容时，也可用导出按钮右侧的箭头选择轨道。每次只导出一条轨道，不叠画、不混入其他轨道的声音。

复制短于 10 秒的片段时，副本插在原片段之后；10 秒及以上则复制到下方的新轨道。副本可独立编辑，命名不会更改源文件名。

## 多视角对齐

先使用现有的分割和删除功能，分别裁掉各视角开头多余的部分，让要同步的画面落在同一个时间点。删除只影响当前片段，因此可以逐轨完成这一步。

对齐后点击“多选轨道”，依次点击需要联动的轨道，再点击“保存并对齐”。绑定轨左侧会显示玫瑰色标记；此后从组内任意轨道执行分割，所有成员都会在同一时间点原子分割。如果有任一轨道在该位置无法产生有效片段，本次分割不会修改任何轨道。删除始终只删除当前选中的片段，不会传播到其他绑定轨。

需要调整分组时，再次进入“多选轨道”，选中已绑定的轨道后点击“解除绑定”。绑定和解绑都支持撤销与重做。

## 导出

“原画”按所选轨道首个素材的分辨率进行高质量重编码，并非无损复制。选择其他画质后可调整为 1080p、720p、4K 或自定义偶数宽高；比例不一致时补黑边。

帧率以首个素材为准，只读取素材的首个普通视频流和首个音频流。混剪有声、无声素材时，无声片段会补静音。编码器在导出窗口的“编码设置”中选择；NVENC 检测通过时默认使用 NVIDIA，否则使用 CPU。

导出可以取消，不覆盖源文件或已有文件。目前支持 SDR 视频，不支持 HDR、项目保存、多轨叠画 / 混音、转场或字幕。

## 资源管理器与更新

在“设置 → 资源管理器集成”添加“使用 Clip 剪辑”右键菜单。Windows 11 中位于“显示更多选项”。不改变默认播放器；移动或删除程序前，请在同一菜单中移除该项。

通过“设置 → 检查更新…”更新程序；Actions 构建用户可开启 Dev 模式。详见[更新指南](updates.md)。

## 遇到问题

### 无法启动

完整解压后仍无法启动，运行程序旁的 `Start-Clip-Diagnostics.cmd`。诊断报告位于 `%LOCALAPPDATA%\Clip\diagnostics`，日常日志位于 `%LOCALAPPDATA%\Clip\logs`。

### 下载或解压失败

Actions 下载需要登录有仓库访问权限的 GitHub 账号，产物保留 14 天。解压报错时，用 `Get-FileHash .\Clip-win-x64.zip -Algorithm SHA256` 与对应构建摘要比较，不一致则重新下载。

### 无法预览或找不到 FFmpeg

系统不支持某种编码时会自动生成兼容预览，大文件可能需要等待；导出仍使用原始素材。Windows N/KN 版需要系统媒体功能包。

FFmpeg 未就绪时，在“设置 → 高级设置 → 选择 FFmpeg 目录…”中选择同时包含 `ffmpeg.exe` 和 `ffprobe.exe` 的目录，发布包中已有 `ffmpeg` 文件夹。

### NVIDIA 编码不可用

在“设置 → 高级设置”中重新检测 NVIDIA，或打开检测详情查看错误。驱动 API 不兼容时，可更新驱动或选择兼容的 FFmpeg；也可以直接使用 CPU 导出。
